Digital Ternary Logic

Simulador visual de lógica ternária balanceada: N = -1, 0 = neutro, P = +1.

Paleta

Exemplos

Chips compostos

Use INPUT/OUTPUT como portas expostas e salve o circuito atual como chip.

Legenda

N = -1
0 = neutro
P = +1
X = indefinido/conflito

Selecione um componente.

Como usar

  1. Adicione componentes pela paleta.
  2. Arraste os blocos no canvas.
  3. Clique em uma saída e depois em uma entrada para ligar fios.
  4. Clique em INPUT para alternar N/0/P.
  5. Use Tick para atualizar registradores e RAM.
  6. Duplo clique em nó/fio para excluir.
